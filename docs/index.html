02 / BEHIND THE GAME

Practice makes a policy.

The same board. A different way to learn.

01

Observe the state

The agent sees the basket column, apple column, and apple row on a 9 × 9 grid.

02

Try an action

Move left, stay, or move right. Early on, it explores. With practice, it trusts its Q-values.

03

Learn from rewards

Catch: +10. Miss: −10. Each apple is one episode. Good decisions gain value over time.

Open the algorithm notebook ＋
Q(s,a) ← Q(s,a) + α [r + γ max Q(s′,a′) − Q(s,a)]

Learning rate α = 0.20 · Discount γ = 0.95 · Epsilon starts at 1.0, decays by ×0.9998 each episode, and stops at 0.03. Terminal steps use the reward alone. Each action drops the apple one row; both positions randomize between apples. AI play uses greedy actions with random tie-breaking and does not train. The chart reports catch rates over batches of 500 training episodes, including exploration.

Training is saved in this browser when local storage is available. Export downloads the Q-table and parameters as JSON. The timer pauses when you switch tabs.
